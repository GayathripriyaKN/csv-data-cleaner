
# CSV Data Cleaner

A Python project that cleans missing values in CSV files using pandas.

## Features
- Reads CSV files
- Detects missing values
- Fills missing numeric values with the median
- Fills missing text values with "Unknown"
- Displays dataset summaries
- Saves the cleaned data to a new CSV file

## Requirements
- Python
- pandas

## How to Run
1. Install dependencies using `pip install -r requirements.txt`
2. Run the program using `python main.py`
